# ADR-002. Local Mode как основной режим

Дата: 2026-07-02  
Статус: accepted

## Контекст

BalanceCraft ориентирован на инди-разработчиков и небольшие команды. Для них критичны простота запуска, отсутствие серверной инфраструктуры и контроль над данными.

Собственное облако на раннем этапе добавляет юридические, инфраструктурные и security-риски.

## Решение

BalanceCraft 1.5 проектируется как Local Mode first.

Основной сценарий:

```text
игра / тестовая сборка
→ локальный JSONL
→ ручной импорт в Desktop
→ локальный анализ
```

Self-hosted Collector рассматривается как будущая опция. BalanceCraft Cloud не входит в ближайшие планы.

## Альтернативы

### Сразу делать облако

Минусы:

- хранение чужих данных;
- privacy/compliance;
- серверная инфраструктура;
- авторизация;
- безопасность;
- поддержка;
- не нужно для портфолио-MVP.

### Сразу делать self-hosted

Минусы:

- нужен backend;
- нужен Docker/deploy;
- выше порог входа;
- отвлекает от Desktop MVP.

## Последствия

Плюсы:

- быстрый MVP;
- меньше рисков с данными;
- проще демонстрация;
- лучше соответствует потребностям solo/indie пользователей.

Минусы:

- нет массовой live-телеметрии в версии 1.5;
- синхронизация между машинами не решается;
- server pipeline откладывается.
