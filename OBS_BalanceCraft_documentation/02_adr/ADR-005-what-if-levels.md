# ADR-005. Уровни What-if анализа

Дата: 2026-07-02  
Статус: accepted

## Контекст

What-if может быть полезной фичей, но опасно обещать точную симуляцию игры по сырым логам. Чтобы сценарный анализ не вводил пользователя в заблуждение, нужно явно разделить уровни точности.

## Решение

What-if делится на четыре уровня:

1. Parameter Impact — оценка потенциального влияния.
2. Counterfactual Replay — пересчёт истории при новых параметрах.
3. Model Simulation — симуляция по явно заданной модели.
4. External Game Simulation — прогон сценария внешней игрой/симулятором.

BalanceCraft 1.5 включает Level 1 и ограниченный Level 2.

## Альтернативы

### Сделать один общий What-if

Минусы:

- непонятно, что именно считается;
- высокий риск false-аналитики;
- пользователь может принять приближение за точный прогноз.

### Отложить What-if полностью

Плюсы:

- проще MVP.

Минусы:

- теряется важная продуктовая особенность;
- сложнее показать отличие от обычных графиков.

## Последствия

Плюсы:

- честная коммуникация точности;
- понятный roadmap;
- можно начать с простого уровня;
- не блокирует будущую симуляцию.

Минусы:

- требуется UI для confidence status;
- нужно аккуратно писать тексты вывода;
- часть пользователей может ожидать большего.
