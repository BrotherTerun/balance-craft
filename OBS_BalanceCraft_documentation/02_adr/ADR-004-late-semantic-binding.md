# ADR-004. Позднее семантическое связывание

Дата: 2026-07-02  
Статус: accepted

## Контекст

Игры используют разные названия событий и полей. Поле `amount` может быть золотом, опытом, уроном, очками действия или любым другим значением. Автоматически и надёжно понять смысл данных без контекста невозможно.

## Решение

BalanceCraft импортирует события как нейтральные данные и не назначает им смысл автоматически.

Смысл задаётся через Binding Wizard:

```text
переменная шаблона
→ source path
→ event_type filter
→ aggregation
→ label
```

Пример:

```text
flow_in → attributes.amount where event_type = resource_gained
flow_out → attributes.amount where event_type = resource_spent
```

## Альтернативы

### Автоматически угадывать смысл

Минусы:

- высокий риск ложных выводов;
- разные игры называют поля по-разному;
- пользователь теряет контроль;
- сложно объяснить ошибки.

### Требовать фиксированную схему событий

Минусы:

- выше порог интеграции;
- хуже для существующих логов;
- меньше универсальность.

## Последствия

Плюсы:

- гибкость;
- честная интерпретация;
- можно работать с разными играми;
- меньше false-аналитики.

Минусы:

- нужен хороший UX мастера;
- пользователь должен понимать свои данные;
- первый результат требует настройки, если нет демо или автопредложений.
