# ADR-006. Self-hosted Collector вне MVP 1.5

Дата: 2026-07-02  
Статус: accepted

## Контекст

Self-hosted Collector полезен для массовой телеметрии, но требует отдельного backend, авторизации, endpoint-ов, хранения, экспорта, документации, Docker/deploy и security defaults.

Для 48-часового портфолио-MVP это слишком большой объём.

## Решение

Self-hosted Collector не входит в BalanceCraft 1.5.

Модель данных, SDK-формат и privacy-документы проектируются так, чтобы Collector можно было добавить позднее без смены базовой концепции.

## Альтернативы

### Включить Collector в MVP

Минусы:

- риск не закончить Desktop;
- больше security и privacy вопросов;
- сложнее демо;
- выше порог запуска.

### Никогда не делать Collector

Минусы:

- ограничение для массовых плейтестов;
- меньше потенциал продукта после MVP.

## Последствия

Плюсы:

- фокус на Desktop;
- быстрее рабочий портфолио-кейс;
- меньше инфраструктурных рисков;
- local-first позиция остаётся чёткой.

Минусы:

- нет live-сбора данных;
- SDK server-sync откладывается;
- массовые тесты требуют ручного экспорта.
